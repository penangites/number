# Security Policy

If you discover a security vulnerability in this package, please report it
privately — **do not open a public issue**.

- Email: [security@penang.today](mailto:security@penang.today)
- Or use [GitHub's private vulnerability reporting](https://github.com/penangites/number/security/advisories/new)

You will receive a response as soon as possible. Please include a description
of the issue and steps to reproduce it. Security fixes are released for the
latest major version.
